# Screenshots Directory

This directory contains output screenshots for the Graph Engine algorithms.

## Directory Structure

```
screenshots/
├── README.md                    # This file
├── CAPTURE_GUIDE.md             # Detailed capture instructions
├── dfs_output.png               # DFS algorithm output screenshot
├── bfs_output.png               # BFS algorithm output screenshot
├── dijkstra_output.png          # Dijkstra algorithm output screenshot
├── bellman_ford_output.png      # Bellman-Ford algorithm output screenshot
├── floyd_warshall_output.png    # Floyd-Warshall algorithm output screenshot
├── kruskal_output.png           # Kruskal MST algorithm output screenshot
├── prim_output.png              # Prim MST algorithm output screenshot
├── scc_output.png               # Strongly Connected Components output screenshot
├── maxflow_output.png           # Maximum Flow algorithm output screenshot
├── coloring_output.png          # Graph Coloring algorithm output screenshot
├── dependency_output.png        # Dependency Resolution output screenshot
└── social_output.png            # Social Network Analysis output screenshot
```

## How to Add Screenshots

### For Algorithm Output Screenshots:
1. Run the corresponding example in CLion
2. Take a screenshot of the console output
3. Save as PNG format with the naming convention: `[algorithm]_output.png`
4. Place in this directory
